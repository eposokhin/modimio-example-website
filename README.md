# Example back-end written in Nest  

## Prerequisites  

1. Install dependencies:  

   ```bash
   npm install
   ```

2. You need to have Postgres up and running. Configure the connection via ```.env``` file in the project  

3. Run the project in dev mode:

   ```bash
   npm run start:dev
   ```

## Script for promoting a user to Admin role  

```bash
npm run promote -- --email user@email.com
```
